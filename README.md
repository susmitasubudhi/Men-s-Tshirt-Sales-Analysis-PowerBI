# Men-s-Tshirt-Sales-Analysis-PowerBI|MYSQL
## Objectives
Analyze men's T-shirt sales data to evaluate brand performance, profitability, and pricing strategy using Power BI and MySQL.

## Data Pipeline
CSV → MySQL → Power BI
## Data Cleaning & Transformation
- Removed missing values
- Dropped original_price column
- Created marked_price
- Engineered new features:
  - Discount %
  - Profit %
  - Cost Price
  - ## Tools Used
- MySQL
- Power BI Desktop
- DAX
- Excel / CSV
- ## Key KPIs & Analysis
- Top 5 brands by Discount %
- Top 5 brands by Number of Varieties
- Top 5 brands by Average Profit %
- Top 5 brands by Average Sales Price
- Bottom 5 brands by Average Profit %
- ## Business Insights
- Identified highly discounted brands with low profitability.
- Highlighted brands with maximum product variety.
- Analyzed pricing vs profit relationships.
